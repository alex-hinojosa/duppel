Enable Per-Tab Mode?

Per-tab mode gives each tab a different fingerprint identity. This may increase fingerprint linkability against biometric trackers, because cross-tab hardware contradictions are detectable when the same human operates multiple tabs.

Most users should keep session mode (one identity for all tabs).
